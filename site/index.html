Replx를 끄면 댓글이 다시 보여요. 꺼진 상태에서 댓글을 누르면 그 영역만 직접 숨겨져요.

세 겹으로 숨겨요

자동으로 다 찾기 어려운 만큼, 빗나간 곳은 사용자가 바로잡을 수 있게 만들었어요.

기본 규칙

국내외 주요 커뮤니티·뉴스·영상 사이트 133곳의 댓글 영역 규칙이 들어 있어요. 페이지가 그려지기 전에 숨겨서 깜빡임이 없어요.

자동 탐지

규칙이 없는 사이트에서는 "댓글 12" 같은 이름표, 입력창, 작성자·시간이 반복되는 목록을 보고 댓글 영역을 찾아요. 기사 본문은 건드리지 않아요.

직접 지정

숨길 영역 못 숨긴 댓글을 클릭하면 그 사이트의 규칙이 돼요.

제외할 영역 잘못 숨겨진 곳을 클릭하면 다시 보이고, 앞으로도 숨기지 않아요.

설치

Chrome 웹 스토어에서 설치

Chrome 웹 스토어 등록을 준비하고 있어요. 그 전까지는 아래 순서로 직접 설치할 수 있어요.

  1. 파일 받기Releases에서 최신 zip을 받아 압축을 풀어요.
  2. 개발자 모드 켜기주소창에 chrome://extensions를 입력하고 오른쪽 위의 개발자 모드를 켜요.
  3. 불러오기"압축해제된 확장 프로그램을 로드합니다"를 누르고 압축을 푼 폴더를 골라요.
  4. 고정하기퍼즐 아이콘에서 Replx를 툴바에 고정하고, 열려 있던 탭은 새로고침해요.

개인정보

Replx는 규칙 처리와 댓글 탐지를 모두 브라우저 안에서만 해요. 방문 기록이나 웹페이지 내용을 수집하지 않고, 외부 서버와 통신하지 않아요. 설정과 직접 만든 규칙만 Chrome 저장소에 남아요.
